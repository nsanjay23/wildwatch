Overview

WildWatch is an AI-powered system that identifies and classifies animals approaching human-populated areas using real-time object detection models.
The goal is to provide an early warning mechanism that helps reduce human–animal conflict by detecting, classifying, and triggering alert systems when wildlife is nearby.

Features

AI-Based Detection: Uses YOLOv8 for accurate real-time animal detection.
Species Classification: Identifies species and categorizes them as endangered or common.
Alert Mechanism (Planned): Future integration to emit sounds or notifications to deter animals.
Simulation Mode: Allows testing with sample images or videos.
Scalable Architecture: Can be extended to edge devices (Raspberry Pi, Jetson Nano).
